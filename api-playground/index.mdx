## Configure the playground

The site-level playground setting lives under the `api` object in `dubstack.json`.

```json dubstack.json
{
  "api": {
    "openapi": "api-reference/openapi.json",
    "playground": {
      "display": "interactive"
    }
  }
}
```

Use `interactive` when readers should see the full request builder. Use `none` when endpoint pages should show documentation only.

For manual MDX endpoint pages, attach the page to an operation in frontmatter.

```mdx
---
title: Create project
openapi: "POST /v1/projects"
playground: interactive
---
```

## Safety checklist

Before enabling live requests on public docs:

- keep real credentials out of Git and examples
- point `servers` at a safe public API environment
- disable the playground for destructive or internal-only endpoints
- keep CORS, authorization, rate limiting, and audit logging on the API itself
- verify custom-domain and path-mounted docs still route playground requests correctly

The playground improves the reader experience. It does not replace API security controls.
