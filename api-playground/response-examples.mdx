Examples make generated endpoint pages more useful.

Add examples to request bodies, responses, and schema fields so readers see realistic payloads instead of only generic type placeholders.

## Useful examples

Use OpenAPI examples for:

- minimal valid requests
- common success responses
- common validation errors
- enum and field-level examples
- alternate request shapes

Keep examples safe. Do not publish real customer data, private identifiers, or live credentials.

For syntax and patterns, see [Response examples](/api-reference/response-examples).
