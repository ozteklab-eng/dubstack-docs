Use colors to show palettes, design tokens, and semantic color choices directly in docs.

Color swatches are useful for brand guidelines, UI component documentation, theme references, and migration guides where readers need to see both a token name and its value.

## Compact palette

Use the compact variant for a small group of colors.

<Color variant="compact">
  <Color.Item name="primary" value="#15803D" />
  <Color.Item name="accent" value="#07C983" />
  <Color.Item name="surface" value="#FFFFFF" />
  <Color.Item name="text" value="#18181B" />
</Color>

```mdx
<Color variant="compact">
  <Color.Item name="primary" value="#15803D" />
  <Color.Item name="accent" value="#07C983" />
  <Color.Item name="surface" value="#FFFFFF" />
  <Color.Item name="text" value="#18181B" />
</Color>
```

## Table palette

Use the table variant when colors belong to named rows.

<Color variant="table">
  <Color.Row title="Brand">
    <Color.Item name="primary" value="#15803D" />
    <Color.Item name="accent" value="#07C983" />
  </Color.Row>
  <Color.Row title="Neutral">
    <Color.Item name="background" value="#FFFFFF" />
    <Color.Item name="foreground" value="#18181B" />
    <Color.Item name="border" value="#E7E5E4" />
  </Color.Row>
</Color>


## CSS color formats

Color values can use CSS color strings.

<Color variant="compact">
  <Color.Item name="hex" value="#FF5733" />
  <Color.Item name="rgb" value="rgb(51, 255, 87)" />
  <Color.Item name="rgba" value="rgba(51, 87, 255, 0.7)" />
  <Color.Item name="hsl" value="hsl(180, 70%, 55%)" />
  <Color.Item name="oklch" value="oklch(70% 0.2 145)" />
</Color>

```mdx
<Color variant="compact">
  <Color.Item name="hex" value="#FF5733" />
  <Color.Item name="rgb" value="rgb(51, 255, 87)" />
  <Color.Item name="rgba" value="rgba(51, 87, 255, 0.7)" />
  <Color.Item name="hsl" value="hsl(180, 70%, 55%)" />
  <Color.Item name="oklch" value="oklch(70% 0.2 145)" />
</Color>
```

## Properties

<ResponseField name="variant" type="string">
  Display style for the palette. Use `compact` for a grid or `table` for labeled rows.
</ResponseField>

<ResponseField name="Color.Row title" type="string">
  Label shown at the start of a row in the table variant.
</ResponseField>

<ResponseField name="Color.Item name" type="string">
  Token name or readable label for the color.
</ResponseField>

<ResponseField name="Color.Item value" type="string" required>
  CSS color value shown in the swatch and copied in examples.
</ResponseField>

## Guidelines

- Use token names that match your codebase.
- Keep compact palettes short enough to scan.
- Use rows for grouped semantic colors such as brand, surface, text, and state.
- Prefer exact token values over screenshots of palettes.
