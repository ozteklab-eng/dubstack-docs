Tiles show a visual preview with a title and description.

Use tiles when the image or preview matters more than a normal text card: template galleries, UI previews, theme examples, and feature showcases.

## Properties

<ResponseField name="href" type="string">
  URL opened when readers click the tile. Use a root-relative path for another docs page or a full URL for an external page.
</ResponseField>

<ResponseField name="title" type="string">
  Short title shown below the preview.
</ResponseField>

<ResponseField name="description" type="string">
  One sentence that explains where the tile goes or what the preview shows.
</ResponseField>

<ResponseField name="children" type="MDX content" required>
  Preview content. Use images, SVGs, or short visual examples.
</ResponseField>

## Guidelines

- Use landscape preview assets so the tile grid stays balanced.
- Keep descriptions short; tiles should scan like visual navigation.
- Use accessible `alt` text for every image preview.
- Use [cards](/writing-content/cards) instead when the content is text-first.
