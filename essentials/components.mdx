DubStack components let you turn plain Markdown into structured, readable documentation without leaving MDX.

Use components when prose alone would make the page harder to scan. Keep the content real, keep examples short, and use each block for one job.

## Callouts

Use callouts for information that should stand apart from the surrounding text.

<Note>A note adds helpful context without interrupting the main flow.</Note>

<Tip>A tip highlights a shortcut, pattern, or best practice.</Tip>

<Warning>A warning calls out risk, ordering, or breaking behavior.</Warning>

<Info>An info callout adds supporting detail.</Info>

```mdx
<Note>A note adds helpful context without interrupting the main flow.</Note>

<Tip>A tip highlights a shortcut, pattern, or best practice.</Tip>

<Warning>A warning calls out risk, ordering, or breaking behavior.</Warning>

<Info>An info callout adds supporting detail.</Info>
```

## Tabs

Use tabs when readers need to choose between package managers, platforms, or environments.

<Tabs>
  <Tab title="npm">

  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @dubstack/sdk
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @dubstack/sdk
    ```

  </Tab>

## Code groups

Use code groups to show the same example in multiple languages.

<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/beats');
  const beats = await response.json();
  ```

  ```python Python
  import requests
  beats = requests.get('https://api.example.com/beats').json()
  ```

  ```bash cURL
  curl https://api.example.com/beats
  ```
</CodeGroup>
