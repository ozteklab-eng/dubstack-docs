Editor settings control how the dashboard editor behaves for your editing session.

Open the settings panel from the editor toolbar:

1. Go to **Editor**.
2. Click the **Editor options** menu in the top toolbar.
3. Click **Editor settings**.

## Appearance

The **Appearance** section controls how the editor canvas and preview actions behave.

| Setting | What it does |
| --- | --- |
| Fit editor to full width | Expands the editing canvas edge-to-edge instead of using the default writing column. |
| Open live preview in new tab | Opens the rendered preview in a new browser tab when you preview a page. |

These settings affect the dashboard editor only. They do not change the published docs site.

## Publishing controls

Publishing behavior is controlled by your source connection, deployment branch, repository permissions, and branch protection rules.

Use:

- [Branching and publishing](/editor/branching-and-publishing) to understand the editor publish menu.
- [Git essentials](/editor/git-essentials) to understand branches, commits, pull requests, and previews.
- [Git settings](/deployment/github) to configure the primary repository connection.

The editor settings dialog may show publishing-related sections before every control is editable for your deployment. When a publishing option is unavailable in this panel, use your Git provider and deployment settings as the source of truth.

## Chat and AI instructions

Ask Agent and assistant behavior use the configured AI surfaces for your deployment.

Use:

- [Ask Agent in the editor](/editor/ask-agent) for the editor toolbar chat panel.
- [Agent](/ai/agent) for dashboard authoring readiness and repository requirements.

If a chat or instruction setting is unavailable in the editor settings dialog, configure the corresponding Agent or Assistant surface instead.
