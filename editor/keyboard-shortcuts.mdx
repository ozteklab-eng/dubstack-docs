Keyboard shortcuts speed up common editor actions.

On macOS, use `Command`. On Windows and Linux, use `Ctrl`.

| Shortcut | Action |
| --- | --- |
| `Command/Ctrl + K` | Open quick search. |
| `Command/Ctrl + S` | Save the current editor changes. |
| `Command/Ctrl + B` | Toggle the sidebar. |
| `Command/Ctrl + J` | Toggle the assistant panel. |
| `Shift + Command/Ctrl + M` | Toggle visual/source editor mode. |
| `Shift + Command/Ctrl + F` | Toggle the file browser pane. |
| `Escape` | Close open overlays such as search or settings panels. |

## Slash menu

Type `/` on an empty line to open the component menu.

Use it to insert common blocks, callouts, cards, media, code blocks, tabs, accordions, steps, fields, and other supported docs components.

## Rename and settings fields

Many inline rename fields accept:

| Key | Action |
| --- | --- |
| `Enter` | Confirm the rename or field edit. |
| `Escape` | Cancel the edit. |
