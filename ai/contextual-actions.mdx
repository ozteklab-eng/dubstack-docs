Contextual actions are the quick actions shown on published documentation pages.

They help readers copy page content, open a markdown view, send the page to an AI assistant, or connect an external AI tool to the current docs context.

## Common actions

| Action key | Label | What it does |
| --- | --- | --- |
| `copy` | Copy page | Copies the current page content as Markdown. |
| `view` | View as Markdown | Opens a Markdown version of the current page. |
| `assistant` | Ask assistant | Opens the docs assistant with the current page as context. |
| `claude`, `chatgpt`, `perplexity`, `grok`, `aistudio`, `devin`, `windsurf` | External AI actions | Opens or prepares a supported external AI tool with page context. |
| `mcp` | Copy MCP server URL | Copies the public MCP endpoint for the docs site. |
| `add-mcp` | Copy MCP install command | Copies an `npx add-mcp` command for the public MCP endpoint. |
| `cursor` | Connect to Cursor | Copies an MCP JSON block that can be added to Cursor. |
| `vscode` | Connect to VS Code | Copies a VS Code CLI command that adds the public MCP server. |
| `devin-mcp` | Connect to Devin | Copies an MCP JSON block for Devin-compatible MCP configuration. |
| `download-spec` | Download API spec | Opens the public OpenAPI specification download for API reference pages. |

## Configure actions

Configure contextual actions in `dubstack.json`.

```json
{
  "contextual": {
    "enabled": true,
    "options": ["copy", "view", "mcp", "add-mcp", "cursor", "vscode", "claude", "chatgpt", "perplexity"],
    "default": "copy",
    "labels": {
      "copy": "Copy page",
      "view": "View as Markdown",
      "mcp": "Copy MCP server URL",
      "add-mcp": "Copy MCP install command",
      "cursor": "Connect to Cursor",
      "vscode": "Connect to VS Code",
      "claude": "Ask Claude",
      "chatgpt": "Ask ChatGPT",
      "perplexity": "Ask Perplexity"
    }
  }
}
```

Use the smallest set of actions that helps your readers. A short menu is easier to understand and reduces accidental data sharing.

## Public page behavior

Contextual actions use published page content only. They do not expose dashboard settings, unpublished files, private team notes, or protected repository data.

If a page is not published, it is not available through contextual actions on the public site.

## AI tool actions

AI tool actions are useful when readers want to ask a question outside the built-in assistant.

Before enabling an external AI action, review your content policy and make sure the page content is safe to send to that destination. Public docs are already visible, but external tools can have different retention, privacy, or workspace policies.

<Callout type="warning">
  Do not enable external actions for docs that include secrets, private customer details, unreleased product plans, or internal-only procedures.
</Callout>

## MCP actions

MCP actions help developers connect an agent directly to the published docs site.

For public docs, the MCP endpoint is available at:

```text
https://your-docs-domain.com/mcp
```

Readers can use the copied endpoint in clients that support HTTP MCP servers. The public MCP server is read-only and scoped to published docs content.

When `add-mcp` is enabled, the action copies a command like:

```bash
npx add-mcp https://your-docs-domain.com/mcp
```

When `vscode` is enabled, the action copies a VS Code command with a generated HTTP MCP server config for the current docs domain.

When `cursor` or `devin-mcp` is enabled, the action copies an MCP JSON block with the current docs domain and `/mcp` endpoint.

## API spec action

Use `download-spec` on API reference sites when you want readers to download the published OpenAPI specification from the contextual menu.

The action opens:

```text
https://your-docs-domain.com/api/playground/spec
```

For docs mounted under `/docs`, the action uses the matching subpath:

```text
https://your-domain.com/docs/api/playground/spec
```

## Troubleshooting

If an action is missing from a page:

1. Confirm `contextual.enabled` is `true`.
2. Confirm the action key is listed in `contextual.options`.
3. Publish the branch that contains the `dubstack.json` change.
4. Refresh the published page after the update completes.

If an action opens the wrong page, check that canonical URLs and redirects are configured correctly.
