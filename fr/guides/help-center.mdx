Utilisez ce guide lorsque votre site de documentation doit aider les clients à résoudre des questions sur le produit sans avoir à contacter le support.

Un centre d'aide est différent d'un portail développeur. Il privilégie l'intention du lecteur, les tâches courantes et l'escalade claire du support plutôt que les détails d'implémentation.

## Commencez par les thèmes de support

Collectez les questions les plus répétées parmi :

- conversations de support
- transferts de vente
- appels d'intégration
- analyse des retours
- mots-clés de recherche avec de mauvais résultats
- questions de l'assistant qui ne se résolvent pas clairement

Groupez les pages en fonction de ce que les lecteurs essaient de faire, et non pas selon votre structure interne.

## Structure recommandée

| Grouper | Objectif |
| --- | --- |
| Mise en route | Configuration, création de compte, parcours de premier succès. |
| Compte et facturation | Forfaits, factures, utilisateurs, accès et limites. |
| Guides du produit | Guides axés sur les tâches pour des résultats courants. |
| Dépannage | Problèmes connus, états d'erreur, étapes de récupération. |
| Contacter le support | Chemins d'escalade et informations à inclure. |

Maintenez les pages courtes. Un lecteur doit savoir en quelques secondes si la page répond à sa question.

## Rédigez des pages avec la réponse en premier

Pour chaque page :

1. Commencez par la réponse ou le résultat.
2. Listez les prérequis.
3. Fournissez des étapes numérotées.
4. Ajouter des problèmes courants.
5. Lier les pages connexes.

Éviter de cacher la solution sous une explication contextuelle.

## Utiliser des boucles de feedback

Activer le feedback des lecteurs lorsque vous souhaitez que les visiteurs signalent du contenu manquant ou ambigu.

Examiner le feedback avec :

- vues de page
- recherches échouées
- conversations avec l'assistant
- suggestions de workflow

Utilisez le workflow de feedback pour rédiger des améliorations ciblées à partir de problèmes répétés.

## Connectez le contexte de support avec soin

Les intégrations peuvent aider les workflows à utiliser les thèmes de support comme contexte, mais les données de support peuvent contenir des informations sensibles.

Avant de connecter les systèmes de support :

- confirmez que le fournisseur est approuvé pour votre espace de travail
- restreignez l'accès aux données minimales nécessaires
- évitez de copier les données privées des clients dans les documents publics
- examinez les brouillons générés avant la publication
