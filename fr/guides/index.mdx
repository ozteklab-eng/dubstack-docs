Utilisez ces guides lorsque vous connaissez le résultat souhaité et que vous avez besoin du chemin le plus court à travers le produit.

<CardGroup cols={2}>
  <Card title="Créer votre premier site" icon="rocket" href="/fr/quickstart">
    Partez d'un nouvel espace de travail et publiez un site de documentation fonctionnel.
  </Card>
  <Card title="Connecter Git" icon="git-branch" href="/fr/getting-started/connect-git">
    Reliez un dépôt existant et conservez la source de la documentation chez votre fournisseur Git.
  </Card>
  <Card title="Utiliser un dépôt hébergé" icon="cloud" href="/fr/getting-started/skip-git-hosted-repo">
    Laissez dubstack créer une source initiale lorsque vous ne souhaitez pas encore vous connecter à Git.
  </Card>
  <Card title="Publier une référence API" icon="terminal" href="/fr/api-reference/openapi-setup">
    Ajoutez une spécification OpenAPI et générez la documentation des points de terminaison avec un générateur de requêtes.
  </Card>
  <Card title="Configurer la navigation" icon="map" href="/fr/configuration/navigation">
    Organisez les pages, les groupes, les onglets, les icônes et les pages cachées.
  </Card>
  <Card title="Configurer des domaines personnalisés" icon="globe" href="/fr/deployment/custom-domains">
    Pointez un domaine ou un sous-domaine dédié à la documentation vers votre site publié.
  </Card>
  <Card title="Utiliser les déploiements de prévisualisation" icon="git-pull-request" href="/fr/deployment/preview-deployments">
    Révisez les modifications propres à une branche avant leur publication.
  </Card>
  <Card title="Configurer l'automerge" icon="shield-check" href="/fr/deployment/configure-automerge">
    Autorisez les mises à jour de workflow sélectionnées à fusionner automatiquement lorsque votre politique de dépôt le permet.
  </Card>
  <Card title="Comprendre les concepts Git" icon="git-branch" href="/fr/guides/git-concepts">
    Découvrez les notions de dépôt, de branche, de commit, de pull request et de branche de déploiement utilisées par les workflows docs-as-code.
  </Card>
  <Card title="Travailler avec les branches" icon="git-pull-request" href="/fr/guides/branches">
    Rédigez, prévisualisez, révisez et publiez les modifications des documents en toute sécurité.
  </Card>
  <Card title="Migrer une documentation existante" icon="repeat" href="/fr/migration/overview">
    Migrez en toute sécurité un dépôt de documentation existant vers dubstack.
  </Card>
</CardGroup>

## Planifier votre site de documentation

<CardGroup cols={2}>
  <Card title="Documentation pour développeurs" icon="code" href="/fr/guides/developer-documentation">
    Planifiez les références API et SDK, les guides, le journal des modifications et le dépannage destinés aux développeurs.
  </Card>
  <Card title="Base de connaissances interne" icon="building-2" href="/fr/guides/internal-knowledge-base">
    Structurez les runbooks internes, les notes d'architecture, les connaissances sur le produit et les manuels d'équipe.
  </Card>
  <Card title="Centre d'aide" icon="life-buoy" href="/fr/guides/help-center">
    Créez des documents orientés support à partir de questions courantes, de lacunes de recherche et de retours.
  </Card>
  <Card title="Types de contenu" icon="files" href="/fr/guides/content-types">
    Choisissez parmi les guides, les références, les journaux de modifications, les extraits, les ressources et les pages cachées.
  </Card>
  <Card title="Modèles de contenu" icon="layout-template" href="/fr/guides/content-templates">
    Utilisez des modèles de pages répétitifs pour les guides, les références, la résolution de problèmes et les journaux de modifications.
  </Card>
  <Card title="Dispositions personnalisées" icon="layout-template" href="/fr/guides/custom-layouts">
    Décidez quand utiliser la disposition standard de la documentation et quand adopter une disposition Canvas.
  </Card>
  <Card title="Comprendre votre public" icon="users" href="/fr/guides/understand-your-audience">
    Identifiez le lecteur principal, l'objectif de la page et le chemin de navigation avant d'écrire.
  </Card>
  <Card title="Planifier la documentation multilingue" icon="languages" href="/fr/guides/internationalization">
    Structurez les pages traduites, la navigation par langue et les processus de révision.
  </Card>
</CardGroup>

## Guides d'écriture et de qualité

<CardGroup cols={2}>
  <Card title="Accessibilité" icon="accessibility" href="/fr/guides/accessibility">
    Rédigez des documents plus faciles à parcourir, à naviguer, à rechercher et à utiliser avec des technologies d'assistance.
  </Card>
  <Card title="Style et ton" icon="pen-line" href="/fr/guides/style-and-tone">
    Maintenez la cohérence des documents sur le produit, l'API, le workflow et la résolution de problèmes.
  </Card>
  <Card title="Améliorer la qualité de la documentation" icon="chart-line" href="/fr/guides/improving-docs">
    Utilisez les analyses, la recherche, les retours, l'activité de l'assistant et les workflows pour prioriser les améliorations.
  </Card>
  <Card title="Maintenir la documentation dans le temps" icon="calendar-check" href="/fr/guides/maintenance">
    Créez une boucle de maintenance avec la responsabilité, la cadence des révisions, les flux de travail et les règles de dépréciation.
  </Card>
  <Card title="Améliorer le référencement de la documentation" icon="search" href="/fr/guides/seo">
    Utilisez les métadonnées, les titres, les liens internes, les cartes du site et les vérifications de workflow pour améliorer la découverte.
  </Card>
  <Card title="Relier les pages de documentation" icon="link" href="/fr/guides/linking">
    Créez des liens internes, des liens d'ancrage, des sujets connexes et des redirections qui maintiennent la navigabilité des documents.
  </Card>
  <Card title="Utiliser des médias dans la documentation" icon="image" href="/fr/guides/media">
    Ajoutez des images, des captures d'écran, des diagrammes, des contenus intégrés et du texte alternatif sans créer de maintenance inutile.
  </Card>
</CardGroup>

## Guides d'IA et de workflow

<CardGroup cols={2}>
  <Card title="Activer l'assistant" icon="bot" href="/fr/ai/assistant">
