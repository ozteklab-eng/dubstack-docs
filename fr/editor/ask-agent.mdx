**Demander à l'agent** ouvre un panneau de discussion dédié au déploiement depuis la barre d'outils de l'éditeur.

Utilisez-le lorsque vous éditez déjà une page et avez besoin d'aide pour comprendre les documents actuels, trouver du contenu pertinent ou planifier un petit changement de documentation.

## Ouvrir l'agent

1. Ouvrez le tableau de bord.
2. Allez dans **Éditeur**.
3. Ouvrez une page.
4. Cliquez sur **Demander à l'agent** dans la barre d'outils de l'éditeur.

La barre d'outils affiche également le raccourci clavier pour votre plateforme.

Lorsque le panneau s'ouvre, il vous maintient dans l'éditeur et affiche le contexte du déploiement sélectionné. Les réponses de l'agent sont générées par l'IA et peuvent contenir des erreurs. Vérifiez donc les suggestions avant de les appliquer.

## Que demander

Les bons prompts adressés à l'agent de l'éditeur sont ciblés et liés à la page ou à la zone de documentation que vous modifiez.

Exemples :

```text
Find the page that explains custom domains.
```

```text
What should I add to this quickstart before publishing?
```

```text
Summarize the current API reference setup so I can improve this page.
```

## Accès en écriture

L'agent de l'éditeur suit le même cadre d'écriture que l'agent du tableau de bord.

Il peut aider à la rédaction et à la planification, mais les modifications de documentation doivent toujours être revues et publiées via le flux de l'éditeur source.

Pour la préparation à la rédaction, les exigences du dépôt, le contexte d'intégration et le suivi d'utilisation, consultez [Agent](/fr/ai/agent).

## Maintenez le contexte en sécurité

- Ne collez pas de secrets ou d'identifiants privés dans les prompts.
- Limitez les prompts au déploiement sélectionné.
- Vérifiez le contenu généré avant la publication.
- Utilisez la revue de pull request pour les modifications qui affectent les documents de production.
