## Panneaux de l'éditeur

| Panneau | Objectif |
| --- | --- |
| Navigation | Parcourez la structure des documents publiés et ouvrez les pages. |
| Explorateur de fichiers | Ouvrez directement les fichiers source lorsque vous connaissez le chemin. |
| Actifs | Téléchargez et gérez des images ou d'autres actifs de documentation. |
| Configuration du site | Modifiez les paramètres visuels du site pris en charge par `dubstack.json`. |

## Modifier une page

1. Ouvrez le tableau de bord.
2. Accédez à **Éditeur**.
3. Choisissez une page dans **Navigation** ou **Explorateur de fichiers**.
4. Modifiez le contenu MDX.
5. Prévisualisez le résultat rendu.
6. Enregistrez la modification via le flux de publication basé sur la source.

## Prise en charge MDX

L'éditeur prend en charge le Markdown standard ainsi que les composants MDX utilisés par le moteur de rendu de la documentation, notamment les cartes, les encadrés, les onglets, les accordéons, les étapes et les exemples de code.

Utilisez les commandes slash pour insérer des blocs pris en charge sans mémoriser la forme de chaque composant.

## Édition de configuration

La configuration du site est accessible depuis l'éditeur afin que les rédacteurs de documentation puissent mettre à jour la navigation, l'identité visuelle, les paramètres du thème, les références OpenAPI et les actions contextuelles dans le même flux de travail que le contenu des pages.

Les modifications de configuration doivent toujours être revues comme des modifications de code, car elles affectent le site public.

## Bonnes pratiques d'édition

- Gardez chaque modification ciblée.
- Prévisualisez les pages avant publication.
- Évitez de mélanger les réécritures de contenu avec les refontes de navigation dans une seule modification.
- Gardez des extraits réutilisables pour le texte répétitif.
- Validez les actifs avec les pages qui les référencent.
