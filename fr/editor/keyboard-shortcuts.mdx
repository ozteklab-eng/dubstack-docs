Les raccourcis clavier accélèrent les actions courantes de l'éditeur.

Sur macOS, utilisez `Command`. Sur Windows et Linux, utilisez `Ctrl`.

| Raccourci | Action |
| --- | --- |
| `Command/Ctrl + K` | Ouvrir la recherche rapide. |
| `Command/Ctrl + S` | Enregistrer les modifications dans l'éditeur actif. |
| `Command/Ctrl + B` | Activer/désactiver la barre latérale. |
| `Command/Ctrl + J` | Activer/désactiver le panneau de l'assistant. |
| `Shift + Command/Ctrl + M` | Basculer entre l'éditeur visuel et le mode source. |
| `Shift + Command/Ctrl + F` | Activer/désactiver la fenêtre de l'explorateur de fichiers. |
| `Escape` | Fermer les surimpressions ouvertes, comme les panneaux de recherche ou de paramètres. |

## Menu de commandes slash

Tapez `/` sur une ligne vide pour ouvrir le menu des composants.

Utilisez-le pour insérer des blocs courants, des encarts, des cartes, des médias, des blocs de code, des onglets, des accordéons, des étapes, des champs et d'autres composants de documentation pris en charge.

## Champs de renommage et de paramètres

Beaucoup de champs de renommage en ligne acceptent :

| Clé | Action |
| --- | --- |
| `Enter` | Confirmer le renommage ou l'édition du champ. |
| `Escape` | Annuler l'édition. |
