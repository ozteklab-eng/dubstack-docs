Utilisez l'aperçu pour vérifier comment le contenu et les modifications de configuration s'affichent avant de vous fier au site en direct.

L'aperçu est particulièrement important pour les composants MDX, les modifications de navigation, les changements de thème et les pages de référence API générées.

## Ouvrir l'aperçu

Depuis la barre d'outils de l'éditeur, utilisez l'action d'aperçu pour ouvrir la page rendue.

Selon les paramètres de votre éditeur, l'aperçu peut s'ouvrir dans l'espace de travail actuel ou dans un nouvel onglet de navigateur.

## À vérifier

Avant de publier, vérifiez :

- les titres et la table des matières s'affichent correctement
- les encadrés, les cartes, les onglets, les accordéons et les blocs de code ont un aspect correct
- les images et les ressources s'affichent
- la navigation inclut les bonnes pages
- les pages de référence API affichent la bonne méthode, le chemin, les paramètres, le corps et les réponses
- les changements de thème ont un aspect correct en mode clair et en mode sombre

## Aperçu et site en direct

| Surface | Objectif |
| --- | --- |
| Aperçu de l'éditeur | Revue rapide locale pendant la rédaction. |
| Déploiement d'aperçu | Partagez un site rendu spécifique à une branche pour examen. |
| Site en direct | Documentation de production servie depuis la branche de déploiement. |

Ne considérez pas l'aperçu de l'éditeur comme le dernier contrôle de production. Après la publication, ouvrez l'URL en direct et vérifiez la page déployée.

## Ouvrir l'aperçu dans un nouvel onglet

Les paramètres de l'éditeur incluent une option pour ouvrir l'aperçu en direct dans un nouvel onglet de navigateur.

Utilisez cette fonction lorsque vous souhaitez comparer l'éditeur et les documents rendus côte à côte, ou lorsque vous devez tester la page avec une taille d'écran différente.
