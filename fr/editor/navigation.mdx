La zone de navigation contrôle la manière dont les lecteurs se déplacent dans vos documents.

La navigation est stockée dans `dubstack.json`, donc les modifications effectuées dans l'éditeur font partie du même flux de publication basé sur la source que les modifications des pages.

## Navigation et explorateur de fichiers

| Panneau | Utilisez-le pour |
| --- | --- |
| Navigation | Ordre des pages, groupes, étiquettes, icônes et accès à la configuration du site. |
| Explorateur de fichiers | Fichiers sources, pages non listées, ressources, fichiers de configuration et dossiers. |

Un fichier peut exister dans le dépôt sans apparaître dans la navigation. Cela est utile pour les brouillons, les extraits, les actifs et les pages de support cachées.

## Ouvrir les paramètres de navigation

Passez la souris sur un élément de navigation pour afficher ses actions.

Utilisez l'action Paramètres pour modifier les étiquettes et la configuration spécifique à l'élément. Utilisez les actions Créer pour ajouter des fichiers ou des dossiers là où cela est pris en charge.

## Raccourci de configuration du site

Le bas du panneau de navigation inclut **Configurations du site**.

Utilisez-le pour modifier les paramètres visuels et d'exécution pris en charge par `dubstack.json`, notamment la marque, le thème, le comportement de navigation, la recherche, les paramètres de référence API, les redirections, le référencement (SEO) et les surfaces d'extensions.

## Maintenez la navigation révisable

Les modifications de navigation affectent la structure du site public. Traitez-les comme des modifications de code :

- gardez les étiquettes courtes et prévisibles
- évitez de déplacer de nombreuses pages en même temps lors d'une réécriture de contenu
- prévisualisez le site avant de le publier
- vérifiez les liens internes après avoir déplacé ou renommé des pages
