Utilisez des couleurs pour afficher directement les palettes, les jetons de conception et les choix de couleurs sémantiques dans les documents.

Les échantillons de couleurs sont utiles pour les guides de marque, la documentation des composants UI, les références de thèmes et les guides de migration, où les lecteurs doivent voir à la fois le nom d'un jeton et sa valeur.

## Palette compacte

Utilisez la variante compacte pour un petit groupe de couleurs.

<Color variant="compact">
  <Color.Item name="primary" value="#15803D" />
  <Color.Item name="accent" value="#07C983" />
  <Color.Item name="surface" value="#FFFFFF" />
  <Color.Item name="text" value="#18181B" />
</Color>

```mdx
<Color variant="compact">
  <Color.Item name="primary" value="#15803D" />
  <Color.Item name="accent" value="#07C983" />
  <Color.Item name="surface" value="#FFFFFF" />
  <Color.Item name="text" value="#18181B" />
</Color>
```

## Palette en tableau

Utilisez la variante en tableau lorsque les couleurs appartiennent à des lignes nommées.

<Color variant="table">
  <Color.Row title="Marque">
    <Color.Item name="primary" value="#15803D" />
    <Color.Item name="accent" value="#07C983" />
  </Color.Row>
  <Color.Row title="Neutre">
    <Color.Item name="background" value="#FFFFFF" />
    <Color.Item name="foreground" value="#18181B" />
    <Color.Item name="border" value="#E7E5E4" />
  </Color.Row>
</Color>

```mdx
<Color variant="table">
  <Color.Row title="Brand">
    <Color.Item name="primary" value="#15803D" />

  </Color.Row>
  <Color.Row title="Neutral">

    <Color.Item name="border" value="#E7E5E4" />
  </Color.Row>
</Color>
```

## Formats de couleurs CSS

Les valeurs de couleur peuvent utiliser des chaînes de couleur CSS.

<Color variant="compact">
  <Color.Item name="hex" value="#FF5733" />
  <Color.Item name="rgb" value="rgb(51, 255, 87)" />
  <Color.Item name="rgba" value="rgba(51, 87, 255, 0.7)" />
  <Color.Item name="hsl" value="hsl(180, 70%, 55%)" />
  <Color.Item name="oklch" value="oklch(70% 0.2 145)" />
</Color>

```mdx
<Color variant="compact">
  <Color.Item name="hex" value="#FF5733" />
  <Color.Item name="rgb" value="rgb(51, 255, 87)" />
  <Color.Item name="rgba" value="rgba(51, 87, 255, 0.7)" />
  <Color.Item name="hsl" value="hsl(180, 70%, 55%)" />
  <Color.Item name="oklch" value="oklch(70% 0.2 145)" />
</Color>
```

## Propriétés

<ResponseField name="variant" type="string">
  Style d'affichage de la palette. Utilisez `compact` pour une grille ou `table` pour des lignes étiquetées.
</ResponseField>

<ResponseField name="Color.Row title" type="string">
  Étiquette affichée au début d'une ligne dans la variante en tableau.
</ResponseField>

<ResponseField name="Color.Item name" type="string">
  Nom du jeton ou étiquette lisible pour la couleur.
</ResponseField>

<ResponseField name="Color.Item value" type="string" required>
  Valeur de couleur CSS affichée dans l'échantillon et copiée dans les exemples.
</ResponseField>

## Guides

- Utilisez des noms de jetons qui correspondent à votre codebase.
- Maintenez les palettes compactes assez courtes pour être scannées.
- Utilisez des lignes pour les couleurs sémantiques regroupées telles que marque, surface, texte et état.
- Privilégiez les valeurs exactes des jetons plutôt que des captures d'écran de palettes.
