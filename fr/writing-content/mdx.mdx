MDX est le format de page pour les docs de dubstack.

Utilisez Markdown pour la rédaction normale et les composants MDX pour les blocs structurés tels que les cartes, les rappels, les onglets, les onglets déroulants, les champs de paramètres et les exemples de code.

## Frontmatter de la page

Chaque page doit commencer par un frontmatter :

```mdx
---
title: Authentication
description: Learn how to authenticate requests to the Acme API.
icon: key
---
```

Champs courants :

| Champ | Objectif |
| --- | --- |
| `title` | Titre de la page dans le navigateur, la recherche, la navigation et le contexte de l'assistant. |
| `description` | Résumé court de la page pour la recherche et les aperçus. |
| `icon` | Icône facultative pour la navigation et le chrome de la page. |
| `openapi` | Liaison d'opération facultative pour les pages de référence API. |
| `hidden` | Masquer une page de la navigation normale lorsqu'elle est prise en charge par la configuration du site actuelle. |

## Bases de Markdown

```mdx
# Main heading

Use short paragraphs and descriptive headings.

## Steps

1. Create a token.
2. Store it securely.
3. Send it with each request.

## Notes

- Keep examples current.
- Link to related pages.
- Avoid duplicating long explanations across many pages.
```

## Liens

Utilisez des liens relatifs à la racine pour les pages du même site de documentation :

```mdx
Read the [quickstart](/quickstart) before configuring authentication.
```

Utilisez des URL complètes pour les sites externes :

```mdx
Open the [status page](https://status.example.com).
```

## Images

Référez-vous aux ressources stockées dans le dépôt avec des chemins relatifs ou relatifs à la racine :

```mdx
![dubstack light logo](/logo/light.svg)
```

Utilisez un texte alternatif descriptif pour que les lecteurs et les outils d'IA comprennent le contexte de l'image.

## Composants

Utilisez des composants pour le contenu structuré :

```mdx
<Callout type="info">
  Store production credentials in your secret manager, not in docs.
</Callout>
```

```mdx
<CardGroup cols={2}>
  <Card title="Quickstart" icon="zap" href="/quickstart">
    Build your first docs site.
  </Card>
  <Card title="Configuration" icon="settings" href="/configuration/dubstack-json">
    Configure navigation, theme, and behavior.
  </Card>
</CardGroup>
```

## Rédaction pour les outils d'IA

Les documents publiés sont utilisés par la recherche, l'assistant et les outils publics MCP. Rendez les pages plus faciles à retrouver en :

- utiliser des titres spécifiques
- définir les termes du produit avant de les utiliser
- garder les étapes de configuration ordonnées
- ajouter des exemples près de l'explication pertinente
- lier les pages connexes au lieu de compter sur du texte dupliqué

<Callout type="info">
  Les fichiers MDX sont du contenu source. Validez-les dans le dépôt connecté et publiez-les avant d'attendre des modifications sur le site en direct.
</Callout>
