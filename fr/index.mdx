dubstack aide les équipes à publier la documentation pour développeurs, les références d'API et le contenu prêt à l'IA à partir de sources Git.

Utilisez ces documents pour créer un site, connecter le contrôle de version, configurer l'interface de documentation, publier les références d'API et préparer vos documents pour le trafic en production.

## Surfaces de produit

| Surface | À quoi cela sert |
| --- | --- |
| Tableau de bord | Gérez les sites, les workflows de l'éditeur, l'accès des équipes, la facturation, les paramètres et l'activité de publication. |
| Éditeur | Mettez à jour les pages MDX, les actifs, la navigation et la configuration du site depuis le tableau de bord. |
| Interface de documentation | Générez des sites de documentation de production à partir de MDX Git, des spécifications OpenAPI et de `dubstack.json`. |
| Référence d'API | Publiez les documents d'endpoint et les environnements de test du navigateur à partir des spécifications OpenAPI. |
| Assistant | Répondez aux questions des lecteurs à partir des documents publiés avec des sources liées. |
| MCP public | Permettez aux outils d'IA de rechercher et d'inspecter les documents publiés via un serveur MCP en lecture seule. |
| Theme Studio | Personnalisez les expériences de documentation Enterprise avec des contrôles de mise en page visuelle. |
| Aperçus de wikis publics | Aperçu des dépôts publics avant la réclamation ou l'adoption. |

## Chemin recommandé

1. Créez un site depuis le tableau de bord.
2. Connectez-vous à Git ou commencez avec un dépôt hébergé.
3. Modifiez le contenu initial et la navigation.
4. Publiez et vérifiez le site de documentation en direct.
5. Ajoutez des références API, les paramètres de l'assistant et des domaines personnalisés lorsque le site de base est stable.

<Callout type="info">
  Le site de documentation publique est alimenté par le même chemin de publication source que vos clients utilisent. Les modifications doivent être validées, synchronisées et vérifiées sur le locataire en direct avant de les utiliser.
</Callout>
