L'API Playground permet aux lecteurs d'inspecter les détails des points de terminaison, de copier des exemples de requêtes et d'envoyer des requêtes en direct depuis les pages de référence API publiées lorsque le point de terminaison est sûr pour une utilisation interactive.

Utilisez cette page comme point de départ pour configurer, sécuriser et déboguer la documentation API interactive.

## Configurer l'API Playground

Le paramètre de l'API Playground au niveau du site se trouve dans l'objet `api` de `dubstack.json`.

```json dubstack.json
{
  "api": {
    "openapi": "api-reference/openapi.json",
    "playground": {
      "display": "interactive"
    }
  }
}
```

Utilisez `interactive` lorsque les lecteurs doivent voir le générateur de requêtes complet. Utilisez `none` lorsque les pages de point de terminaison doivent afficher uniquement la documentation.

Pour les pages MDX manuelles des points de terminaison, reliez la page à une opération dans le frontmatter.

```mdx
---
title: Create project
openapi: "POST /v1/projects"
playground: interactive
---
```

## Liste de vérification de sécurité

Avant d'activer les requêtes en direct sur les documents publics :

- gardez les identifiants réels hors de Git et des exemples
- pointez `servers` vers un environnement API public sécurisé
- désactivez l'API Playground pour les points de terminaison destructifs ou réservés aux internes
- gardez les contrôles CORS, l'autorisation, la limitation de débit et la journalisation d'audit sur l'API elle-même
- vérifiez que les documents avec domaine personnalisé et montés sur un chemin routent correctement les requêtes de l'API Playground

L'API Playground améliore l'expérience utilisateur. Il ne remplace pas les contrôles de sécurité de l'API.
