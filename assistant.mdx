The public assistant answers reader questions from the docs that are already published for the current site.

It is separate from the dashboard agent. The assistant retrieves and summarizes documentation; it does not edit files or open pull requests.

## Good assistant answers start with good docs

- Use descriptive headings.
- Keep procedures in ordered steps.
- Add examples for configuration and API usage.
- Link related pages so retrieval can find the right context.
- Keep private or unpublished information out of public pages.
