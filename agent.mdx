The dashboard agent helps trusted workspace members maintain documentation from the dashboard, Slack, workflows, and connected tools.

Use the agent when the task should create or update documentation. Use the public assistant when readers only need answers from published docs.

## Common setup path

1. Connect a Git provider for the docs repository.
2. Confirm the agent readiness panel shows a usable published docs index.
3. Connect any integrations the agent needs for the task.
4. Ask for a bounded documentation change.
5. Review the generated pull request or merge request before publishing.
