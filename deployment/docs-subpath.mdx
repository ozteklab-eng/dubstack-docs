Use a `/docs` subpath when your main website already lives on the root domain and you want documentation to appear under the same hostname.

```text
example.com          -> your main website
example.com/docs     -> your dubstack documentation site
```

## How it differs from a custom subdomain

A custom subdomain such as `docs.example.com` is host-based. You point DNS at dubstack and the full hostname serves your docs.

A subpath such as `example.com/docs` is path-based. DNS cannot point only one path to dubstack. The application, edge worker, or reverse proxy that owns `example.com` must route `/docs` and `/docs/*` to the dubstack origin for that site.

## Requirements

To use a subpath, you need:

- A published dubstack site.
- Control over the root website or edge proxy for the domain.
- A route that forwards `/docs` and all nested paths to the dubstack origin.
- The ability to preserve the original request method, query string, body, and response headers.
- The ability to forward `X-Forwarded-Host`, `X-Public-Host`, and `X-Forwarded-Proto`.
- The ability to forward `X-Docs-Base-Path` and `X-Public-Mcp-Url` when public MCP is enabled.

## Enable subpath hosting

1. Open your site in the dubstack dashboard.
2. Go to **Settings → Deployment → Custom domain**.
3. Enable **Host at `/docs`**.
4. Enter your root domain, for example `example.com`.
5. Click **Add domain**.
6. Copy the generated origin hostname.

The origin hostname has this shape:

```text
<site>--origin.dubstack.live
```

Proxy page routes to the origin with the `/docs` path preserved:

```text
https://example.com/docs     -> https://<site>--origin.dubstack.live/docs
https://example.com/docs/... -> https://<site>--origin.dubstack.live/docs/...
```

Runtime endpoints and discovery files stay mounted at `/docs` for visitors, but are forwarded to the origin's canonical endpoint path:

```text
https://example.com/docs/api/theme           -> https://<site>--origin.dubstack.live/api/theme
https://example.com/docs/feedback            -> https://<site>--origin.dubstack.live/feedback
https://example.com/docs/llms.txt            -> https://<site>--origin.dubstack.live/llms.txt
https://example.com/docs/mcp                 -> https://<site>--origin.dubstack.live/mcp
https://example.com/docs/.well-known/mcp     -> https://<site>--origin.dubstack.live/.well-known/mcp
```

## Routing model

When a site is mounted at `/docs`, the root website keeps serving everything outside the docs path.

```text
GET /                  -> root website
GET /pricing           -> root website
GET /docs              -> dubstack origin
GET /docs/quickstart   -> dubstack origin
GET /docs/_next/...    -> dubstack origin assets
GET /docs/api/theme    -> dubstack origin API
GET /docs/fonts/...    -> dubstack font assets
GET /docs/llms.txt     -> dubstack origin AI-readable index
GET /docs/skill.md     -> dubstack origin agent skill file
GET /docs/mcp          -> dubstack origin public MCP server
GET /docs/.well-known/* -> dubstack origin discovery metadata
```

Do not strip `/docs` from the public URL seen by users. Your proxy may forward selected runtime paths to their canonical origin path, but it must keep the public mounted URL in forwarded headers so dubstack can generate mounted links, source URLs, assistant calls, search responses, MCP metadata, and LLM indexes.

For public MCP, the client-facing endpoint must stay mounted at `/docs/mcp`. Your proxy should also forward:

```text
X-Docs-Base-Path: /docs
X-Public-Mcp-Url: https://example.com/docs/mcp
```

These headers let dubstack generate public mounted URLs and let MCP discovery and server cards advertise the public mounted URL instead of the raw `--origin.dubstack.live` hostname.

Preserve dubstack response cache headers. In particular, do not cache `/docs/mcp`; it is the MCP Streamable HTTP transport endpoint. Discovery metadata under `/docs/.well-known/mcp*` can be cached normally.

## Cloudflare Worker example

Use this when your root domain is already routed through Cloudflare Workers.

Replace `DOCS_ORIGIN_HOST` and `PUBLIC_HOST` with the values shown in your dubstack dashboard.

```js
const DOCS_ORIGIN_HOST = '<site>--origin.dubstack.live';
const PUBLIC_HOST = 'example.com';
const DOCS_PREFIX = '/docs';
const REWRITABLE_PREFIXES = [
  '/_next/',
  '/api/',
  '/img/',
  '/assets/',
  '/images/',
  '/fonts/',
  '/favicon',
  '/logo',
  '/site.webmanifest',
  '/apple-touch-icon',
  '/robots.txt',
  '/sitemap.xml',
  '/openapi.json',
  '/api-reference/openapi.json',
  '/feedback',
  '/llms',
  '/skill.md',
  '/.well-known/agent-card.json',
  '/.well-known/agent-skills/',
  '/.well-known/skills/',
];

function shouldPrefix(value) {
  return value.startsWith('/') &&
    value !== DOCS_PREFIX &&
    !value.startsWith(`${DOCS_PREFIX}/`) &&
    REWRITABLE_PREFIXES.some((prefix) => value.startsWith(prefix));
}

function prefixValue(value) {
  return shouldPrefix(value) ? `${DOCS_PREFIX}${value}` : value;
}

function normalizeHostname(value) {
  return String(value || '')
    .trim()
    .toLowerCase()
    .replace(/^https?:\/\//, '')
    .replace(/\/.*$/, '')
    .replace(/:\d+$/, '');
}

function withDocsPrefix(pathname) {
  if (pathname === DOCS_PREFIX || pathname.startsWith(`${DOCS_PREFIX}/`)) return pathname;
  if (pathname === '/') return DOCS_PREFIX;
  return `${DOCS_PREFIX}${pathname.startsWith('/') ? pathname : '/' + pathname}`;
}

function prefixLocationValue(value) {
  const trimmed = String(value || '').trim();
  if (!trimmed || trimmed.startsWith('//')) return value;

  if (/^https?:\/\//i.test(trimmed)) {
    try {
      const url = new URL(trimmed);
      const hostname = normalizeHostname(url.hostname);
      if (hostname !== DOCS_ORIGIN_HOST && hostname !== PUBLIC_HOST) return value;
      url.protocol = 'https:';
      url.hostname = PUBLIC_HOST;
      url.port = '';
      url.pathname = withDocsPrefix(url.pathname);
      return url.toString();
    } catch {
      return value;
    }
  }

  if (!trimmed.startsWith('/')) return value;

  try {
    const url = new URL(trimmed, 'https://docs.local');
    return new URL(`${withDocsPrefix(url.pathname)}${url.search}${url.hash}`, `https://${PUBLIC_HOST}`).toString();
  } catch {
    return new URL(withDocsPrefix(trimmed), `https://${PUBLIC_HOST}`).toString();
  }
}

function isRedirectStatus(status) {
  return status >= 300 && status < 400;
}

function prefixSrcSet(value) {
  return value
    .split(',')
    .map((candidate) => {
      const leading = candidate.match(/^\s*/)?.[0] || '';
      const trimmed = candidate.trim();
      if (!trimmed) return candidate;
      const [url, ...descriptors] = trimmed.split(/\s+/);
      return `${leading}${[prefixValue(url), ...descriptors].join(' ')}`;
    })
    .join(',');
}

function prefixCssUrls(value) {
  return value.replace(/url\((['"]?)(\/[^'")]+)\1\)/g, (match, quote, url) => {
    const next = prefixValue(url);
    return next === url ? match : `url(${quote}${next}${quote})`;
  });
}

class DocsAssetPrefixer {
  element(element) {
    for (const attr of ['href', 'src', 'action', 'poster']) {
      const value = element.getAttribute(attr);
      if (value) element.setAttribute(attr, prefixValue(value));
    }

    const srcset = element.getAttribute('srcset');
    if (srcset) element.setAttribute('srcset', prefixSrcSet(srcset));

    const style = element.getAttribute('style');
    if (style) element.setAttribute('style', prefixCssUrls(style));
  }
}

function prefixResponseHeaders(response) {
  const headers = new Headers(response.headers);

  const link = headers.get('link');
  if (link) {
    headers.set('link', link.replace(/<([^>]+)>/g, (match, href) => (
      shouldPrefix(href) ? `<${DOCS_PREFIX}${href}>` : match
    )));
  }

  const location = headers.get('location');
  if (location) {
    headers.set('location', prefixLocationValue(location));
  }

  headers.delete('content-length');
  return cloneResponseWithHeaders(response, headers);
}

function cloneResponseWithHeaders(response, headers) {
  return new Response(isRedirectStatus(response.status) ? null : response.body, {
    status: response.status,
    statusText: response.statusText,
    headers,
  });
}

function shouldProxy(pathname) {
  return pathname === DOCS_PREFIX || pathname.startsWith(`${DOCS_PREFIX}/`);
}

function stripDocsPrefix(pathname) {
  if (pathname === DOCS_PREFIX) return '/';
  if (pathname.startsWith(`${DOCS_PREFIX}/`)) {
    return pathname.slice(DOCS_PREFIX.length) || '/';
  }
  return null;
}

function mapMountedPathToOrigin(pathname) {
  const stripped = stripDocsPrefix(pathname);
  if (stripped === '/mcp' || stripped === '/mcp/') return '/mcp';
  if (stripped === '/.well-known/mcp' || stripped === '/.well-known/mcp.json') return stripped;
  if (stripped?.startsWith('/.well-known/mcp/')) return stripped.replace(/\/+$/, '');
  if (stripped === '/.well-known/agent-card.json') return stripped;
  if (stripped?.startsWith('/.well-known/agent-skills/') || stripped?.startsWith('/.well-known/skills/')) {
    return stripped.replace(/\/+$/, '');
  }
  if (stripped && REWRITABLE_PREFIXES.some((prefix) => stripped.startsWith(prefix))) return stripped;
  return pathname;
}

function buildProxyRequest(request) {
  const target = new URL(request.url);
  target.hostname = DOCS_ORIGIN_HOST;
  target.protocol = 'https:';
  target.pathname = mapMountedPathToOrigin(target.pathname);

  const proxyRequest = new Request(target, request);
  proxyRequest.headers.set('X-Forwarded-Host', PUBLIC_HOST);
  proxyRequest.headers.set('X-Public-Host', PUBLIC_HOST);
  proxyRequest.headers.set('X-Forwarded-Proto', 'https');
  proxyRequest.headers.set('X-Docs-Base-Path', DOCS_PREFIX);
  proxyRequest.headers.set('X-Public-Mcp-Url', `https://${PUBLIC_HOST}${DOCS_PREFIX}/mcp`);
  return new Request(proxyRequest, { redirect: 'manual' });
}

export default {
  async fetch(request) {
    const url = new URL(request.url);

    if (!shouldProxy(url.pathname)) {
      return fetch(request);
    }

    const response = prefixResponseHeaders(await fetch(buildProxyRequest(request)));
    if (isRedirectStatus(response.status)) return response;

    const contentType = response.headers.get('content-type') || '';

    if (contentType.includes('text/css')) {
      const css = await response.text();
      return new Response(prefixCssUrls(css), {
        status: response.status,
        statusText: response.statusText,
        headers: response.headers,
      });
    }

    if (!contentType.includes('text/html')) return response;

    return new HTMLRewriter()
      .on('[href],[src],[action],[poster],[srcset],[style]', new DocsAssetPrefixer())
      .transform(response);
  }
};
```

Keep these rewrites limited to `/docs` traffic. The dubstack dashboard generates a site-specific copy of this Worker snippet with your actual origin hostname and public host filled in.

## Generic reverse proxy example

For Nginx-style reverse proxies, preserve `/docs` for page routes and forward runtime endpoints to their canonical origin paths.

```nginx
location = /docs/mcp {
  proxy_pass https://<site>--origin.dubstack.live/mcp;
  proxy_set_header X-Forwarded-Host $host;
  proxy_set_header X-Public-Host $host;
  proxy_set_header X-Forwarded-Proto https;
  proxy_set_header X-Docs-Base-Path /docs;
  proxy_set_header X-Public-Mcp-Url https://$host/docs/mcp;
}

location /docs/.well-known/ {
  rewrite ^/docs(/.*)$ $1 break;
  proxy_pass https://<site>--origin.dubstack.live;
  proxy_set_header X-Forwarded-Host $host;
  proxy_set_header X-Public-Host $host;
  proxy_set_header X-Forwarded-Proto https;
  proxy_set_header X-Docs-Base-Path /docs;
  proxy_set_header X-Public-Mcp-Url https://$host/docs/mcp;
}

location ~ ^/docs/(_next/|api/|img/|assets/|images/|fonts/|favicon|logo|site\.webmanifest|apple-touch-icon|web-app-manifest|robots\.txt|sitemap\.xml|openapi\.json|api-reference/openapi\.json|feedback|llms|skill\.md) {
  rewrite ^/docs(/.*)$ $1 break;
  proxy_pass https://<site>--origin.dubstack.live;
  proxy_set_header X-Forwarded-Host $host;
  proxy_set_header X-Public-Host $host;
  proxy_set_header X-Forwarded-Proto https;
  proxy_set_header X-Docs-Base-Path /docs;
  proxy_set_header X-Public-Mcp-Url https://$host/docs/mcp;
}
```

If your proxy strips or rewrites response headers, preserve the headers returned by dubstack for `/docs/.well-known/mcp*` and keep `/docs/mcp` uncached.

## Validation

After the route is configured, check:

- `/docs` loads the docs homepage.
- `/docs/quickstart` or another nested page loads directly after a refresh.
- Browser dev tools show static assets loading from `/docs/_next/...`, not from `/_next/...`.
- `/docs/api/theme` returns site theme data.
- `/docs/llms.txt` lists docs URLs under `/docs`.
- `/docs/skill.md` returns Markdown.
- `/docs/feedback` returns the feedback endpoint response and is not cached.
- `/docs/mcp` returns the public MCP transport response and is not cached.
- `/docs/.well-known/mcp` returns a discovery document whose `url` is `https://example.com/docs/mcp`.
- `/docs/.well-known/mcp/server-card.json` lists the public MCP tools.
- `/docs/.well-known/agent-skills/index.json` returns the agent-skills manifest.
- `/docs/.well-known/agent-card.json` returns the agent card.
- Search, assistant, API playground, and page navigation work from the mounted path.
- Links inside the docs keep users under `/docs`.

## Troubleshooting

### The docs homepage works, but nested pages 404

Your proxy probably handles `/docs` but not `/docs/*`. Add the wildcard route.

### Static assets load from the root domain

Make sure your proxy preserves the `/docs` prefix and forwards the generated response headers. If your root app rewrites HTML, it must not remove `/docs` from dubstack asset URLs.

### The site shows the raw origin URL

Forward `X-Forwarded-Host`, `X-Public-Host`, and `X-Forwarded-Proto`. These headers tell dubstack which public domain is serving the mounted docs.

### The origin hostname appears in search results

Do not link users to `https://<site>--origin.dubstack.live`. That hostname is for proxy traffic only. Direct origin responses are marked `noindex`, but your public links and sitemap should use your mounted domain.

### Claude or another MCP client connects but shows no tools

Check `/docs/.well-known/mcp/server-card.json` and confirm the `url` field points to `https://example.com/docs/mcp`, not the `--origin` hostname. If it points to the origin, forward `X-Public-Mcp-Url` from the proxy and clear any CDN cache for `/docs/.well-known/mcp*`.

If the connector adds successfully but shows no tools or tool calls fail, also confirm the proxy forwards `X-Docs-Base-Path: /docs` and does not cache `/docs/mcp`.

## When to use a subdomain instead

Use a host-based custom domain such as `docs.example.com` when you want the simplest setup. A subdomain only needs DNS and domain verification.

Use `/docs` when sharing the root domain matters more than operational simplicity.
