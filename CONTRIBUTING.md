# Contribute To The Documentation

Thank you for improving the documentation. This guide explains the expected workflow for changes in this repo.

## Local Editing

1. Create a branch for your change.
2. Edit the relevant MDX files.
3. Update `dubstack.json` if navigation, theme, contextual actions, or site settings change.
4. Preview the rendered page in DubStack.
5. Commit the change with a clear message.

## Writing Guidelines

- Start with the reader's goal.
- Put prerequisites before commands.
- Include expected results or verification steps.
- Use consistent product and API terminology.
- Keep code examples minimal but complete.

## MDX Guidelines

- Add frontmatter with `title` and `description` for every page.
- Prefer structured components over long walls of text.
- Keep callouts short and purposeful.
- Use accessible alt text for images.
- Avoid hiding required setup steps inside accordions.

## Review Checklist

- Links resolve correctly.
- Commands are current and copyable.
- Screenshots or images have useful alt text.
- No secrets or private customer information are included.
- The page appears in the intended navigation location.
