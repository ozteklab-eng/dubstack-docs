This document outlines the process for updating documentation based on code changes through the `update_from_code_changes` workflow. The workflow is triggered by code changes and operates in pull request mode, running twice weekly. It uses the `forgejo_pull_request` event source and references the `forgejo:ozteklab/forgejo-docs-smoke@main` repository as read-only context. Any changes to documentation should be made against the connected documentation repository.

The workflow is designed to draft documentation updates from code changes, using the provided repository as a source of context. It does not infer changes outside of the explicitly attached code-change context. The workflow is currently associated with a single merged pull request, which was triggered by a code change and completed on 2026-07-13.

Published documentation is maintained in the `ozteklab-eng/dubstack-docs@product-docs` repository. Key pages include an introduction to dubstack, a guide on creating a site, connecting Git, and deploying documentation. The documentation covers the platform's capabilities, including Git-backed content, API reference generation, and AI-ready surfaces.
