This document outlines the "Update From Code Changes" workflow, which automates the process of generating documentation updates based on changes in a connected source repository. The workflow is triggered by code changes and operates on a schedule of twice per week. It is configured to work with the `forgejo:ozteklab/forgejo-docs-smoke@main` repository, which serves as a read-only context for documentation updates.

The workflow is designed to draft documentation changes in response to code modifications, ensuring that documentation remains aligned with the latest product developments. It is intended to be used in conjunction with the `ozteklab-eng/dubstack-docs@product-docs` repository, where all documentation updates are applied.

The workflow is associated with a specific pull request: `#96 Extend grounded authoring review fixture`, which was merged on 2026-08-29 by `jpnaiken`. The pull request URL is available at `https://git.ozteklab.com/ozteklab/forgejo-docs-smoke/pulls/96`.
