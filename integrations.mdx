Integrations let agent and workflow runs use bounded context from the tools where product work happens.

Only connected integrations are passed to runs. Catalog integrations can appear in the dashboard before they are available so teams can see the planned capability model.

## Connection model

| Connection type | Best for |
| --- | --- |
| Shared | Team-owned systems such as Slack, Jira, Linear, Notion, Confluence, support platforms, and CRM platforms. |
| Personal | User-owned context such as calendars or drive files that should stay scoped to the connected user. |

Connected tools do not change the documentation source of truth. Docs changes still write through the configured Git provider.
