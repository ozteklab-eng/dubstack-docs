## Guidance

- Read the relevant API reference page through the public MCP before giving setup steps.
- Treat generated endpoint pages as derived from the published OpenAPI document.
- Do not invent operation IDs, paths, auth schemes, base URLs, examples, or API keys.
- When a user asks why an endpoint is missing, check the OpenAPI spec location, endpoint visibility controls, and the deployment branch before suggesting renderer changes.
